Bên trong bộ Kit có gì? (What's Inside)

Tải về 1 file IndieHacker-Automation-Kit-v1.0.zip — mở ra là chạy ngay trên Windows, macOS, Linux.

1. bounty_monitor.py

Quét GitHub Search API tìm issue có thưởng (bounty, algora, paid) lọc theo ngôn ngữ, độ mới và số comment ít cạnh tranh. Có chế độ --demo test offline và xuất Terminal / JSON / Markdown.

python scripts/bounty_monitor.py \
  --labels bounty --language python \
  --max-comments 4 --format markdown

2. freelance_pricing_calc.py

Quy đổi mục tiêu thu nhập ròng + thuế + chi phí + giờ không tính tiền thành giá giờ chuẩn, báo giá trọn gói 3 mức (Essential / Recommended / Priority) và ROI hoàn vốn cho khách.

python scripts/freelance_pricing_calc.py \
  --target-income 72000 --tax-rate 0.22 \
  --project-hours 40 --client-monthly-gain 4000

3. proposal_invoice_gen.py

Sinh Invoice hoặc Proposal chuẩn Markdown sạch đẹp từ file JSON hoặc tham số dòng lệnh, tự tính chiết khấu, thuế và tiền cọc 50% — sẵn sàng xuất PDF gửi khách.

python scripts/proposal_invoice_gen.py \
  --mode proposal --config job.json \
  --out proposal_acme.md
